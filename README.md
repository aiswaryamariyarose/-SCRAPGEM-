 # 🍫 ScrapGem — Built from Scrap, Powered by Snacks!

**ScrapGem** is a smart, eco-friendly chocolate vending machine prototype built using recycled cardboard and electronic components. It combines creativity, automation, and technology to create a fun way to dispense KitKat chocolates.

![ScrapGem KitKat Advertisement](images/scrapgem_poster.png)

## 🌟 About the Project

ScrapGem is designed to demonstrate how discarded materials can be transformed into a useful and attractive vending machine. The cardboard body is decorated with KitKat-themed coverings, giving it a colorful chocolate advertisement design.

The prototype integrates electronic components for motion detection, RFID card scanning, display output, and automated chocolate dispensing.

## 🎯 Objectives

- ♻️ Reuse cardboard and recycled materials.
- 🤖 Demonstrate an automated vending mechanism.
- 💳 Explore RFID-based user identification.
- 📟 Display instructions and status messages.
- 🍫 Create an attractive chocolate vending machine prototype.

## 🧰 Components Used

| Component | Purpose |
|---|---|
| Arduino Uno R3 | Main controller |
| RC522 RFID reader | Reads RFID cards |
| SG90 servo motor | Controls the dispensing mechanism |
| DST-013 OLED display | Shows instructions and status |
| SR505 PIR sensor | Detects motion |
| HC-05 Bluetooth module | Enables Bluetooth communication |
| Cardboard and recycled materials | Machine body and structure |
| KitKat wrappers or printed coverings | Exterior decoration |

## ⚙️ How It Works

1. The machine powers on and displays a welcome message.
2. The user presents an RFID card to the reader.
3. The controller processes the card according to the programmed authorization rules.
4. The dispensing mechanism is activated when the required conditions are met.
5. The servo motor moves the mechanism to release a chocolate.
6. The display shows status messages to guide the user.

*Note: RFID authorization and payment are demonstration features unless connected to a real payment system.*
